# 0.2.0 · 独立小窗与窗口翻译

更新日期：2026-10-10（Asia/Shanghai）。本轮是用户明确要求的两项功能更新：开启翻译后小窗独立工作，以及选择已打开的浏览器、游戏或软件窗口进行翻译。

## 使用方法

1. 保留已有 AI 连接，选择英语、日语或韩语。
2. 点“选择窗口”，选中要翻译的窗口，再点“使用这个窗口”和“开始连续翻译”。原来的“或框选区域”仍可使用。
3. 主界面的 × 现在收起主界面，最小化也不会带着小窗消失；翻译继续运行。小窗已经隐藏时也保持隐藏。小窗的“打开主界面”按钮可恢复主界面。
4. 小窗“…”菜单提供选窗口、框选、刷新、设置和退出。两个界面都隐藏后，可双击 Windows 托盘图标恢复主界面，或右键显示小窗。
5. 点“暂停”暂时停止。要结束后台运行，请点“退出软件”，主界面、小窗菜单和托盘都有这个入口。

窗口模式跟随所选窗口的位置和大小，只读取当前可见的内容区，不读取标题栏、隐藏页面或滚动到看不到的内容。最小化、隐藏、关闭或被其他软件遮挡时会暂停；恢复可见后点“开始”。窗口关闭后需重新选择。翻译软件自己的主窗口和小窗在截图排除成功时不构成遮挡；排除失败则要求移开它们。

## Evidence and Gate Decision · 依据与改动决定

- 依据：旧版把小窗的 `Owner` 设为主窗口，主窗口关闭时又释放翻译会话，无法满足用户要求；捕获入口只有固定的屏幕框选区域。
- 用户确认：“选择页面”指选择一个已打开的浏览器、游戏或软件窗口，翻译它当前可见的文字。
- 改动决定：界面生命周期与捕获入口采用 `Local Fix / Local Fix Only`，以用户授权的功能合同限定范围；没有重写翻译、识字或配置模块。
- 授权状态：`approved local fix`，用户已明确要求新增这两项功能；完成本地交付后又要求“同步更新到 GitHub”，因此本次提交源码、更新说明并发布安装版和免安装版。真实 AI 调用和人工验收仍分别保留。
- 第三方能力：窗口列表使用 [EnumWindows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enumwindows)，捕获范围由 [GetClientRect](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getclientrect) 和 [ClientToScreen](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-clienttoscreen) 取得。范围使用实际屏幕像素，与旧截图入口一致。

## Behavior Contract · 行为合同

| 项目 | 本轮约定 |
|---|---|
| 目标行为 | 开始翻译后，关闭或最小化主界面不停止翻译、不隐藏小窗；可从已打开窗口列表选择翻译目标 |
| 输入与输出 | 已选语言、已保存连接、原屏幕区域或指定窗口；原文和译文仍在主界面与小窗显示 |
| 状态归属 | 原 `TranslationSession` 管理翻译；主窗口对象保留在后台协调采集，小窗解除主窗口所有权关系 |
| 新增状态 | 窗口模式记录本次会话的窗口句柄、进程和线程身份；关闭后不按相同标题改绑其他窗口 |
| 兼容 | 框选、三语模型、两种 API、快捷键、配置文件和密钥保护格式保留；不迁移用户设置 |
| 故障处理 | 目标不可见或被遮挡时暂停；截图前后位置变化时丢弃该帧，下一轮重新跟随位置 |
| 退出 | 关闭选择窗口或框选遮罩，取消采集与请求，释放原生资源和托盘，再结束程序 |
| 限制 | 一个目标、一个显示器内的可见内容区；单边最多 8,192 像素，总量最多 1,600 万像素 |

## Change Summary · 改动结果

- 解除小窗对主界面的依附；主界面 × 只收起自身，保持小窗已显示或已隐藏的状态。显式“退出软件”负责清理资源，托盘提供恢复入口。
- 新增窗口选择界面；选中窗口后按当前位置捕获内容区，跟随移动和大小变化。
- 选择取消时保留原目标。目标关闭、隐藏、最小化或被遮挡时暂停，防止把后面的无关软件当作目标。
- 小窗可独立选范围、刷新、暂停、打开设置和恢复主界面。原有框选仍保持屏幕坐标模式。
- 版本号改为 0.2.0；软件为 Windows x64 自包含输出，可直接打开 exe。
